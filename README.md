# 溺れし灯 — THE DROWNED LIGHT

クトゥルー神話モチーフ・グラフィカルポイント＆クリック脱出ゲーム / A Cthulhu Mythos point-and-click escape game

- ファイル: index.html（単一ファイル / single file）
- 対応: PC / スマートフォン（横画面） / PC & smartphone (landscape)
- 言語: 日本語 / English（ゲーム内いつでも切替可能）
- 通信: 不要（完全オフライン動作 / works 100% offline）
- データ保存: ブラウザのローカルストレージ / browser localStorage

------------------------------------------------------------

## 日本語

### 遊び方

1. index.html をブラウザで開きます（ダブルクリック、またはスマホにコピーして開く）。
2. タイトル画面で「ゲーム開始」をタップ。続ける場合は「続きから」または「ロード1 / ロード2」。
3. 画面の对象をタップ / クリックして調査し、持ち物と組み合わせて脱出の手がかりを集めます。

### 操作方法

- 对象をタップ / クリック: 調査・移動
- 持ち物アイテムを1回タップ: 選択（枠が金色になる）
- 選択中に他の对象をタップ: そのアイテムを使用
- 同じアイテムをもう一度タップ: そのまま使う／選択解除
- HINT ボタン: 現在地と進行度に応じたヒント
- 右上「音♪」: 効果音 ON / OFF（設定は記憶されます）
- 右上「日本語 / EN」: 言語切替（設定は記憶されます）
- メニュー: セーブ1 / セーブ2 / ロード1 / ロード2 / オート読込 / 最初から / タイトルへ

### セーブデータ

- 自動保存: 移動のたびにオートスロットへ保存
- 手動保存: メニューからスロット1・2へ（上書き確認あり）
- 保存先はブラウザのローカルストレージです。ブラウザ・端末を替えると引き継げません

### ゲームシステム

- 12の場所: 寝室 / キッチン / 玄関ホール / 階段室 / 灯室 / 地下貯蔵庫 / 埠頭 / ボート / 岩場 / 海底洞窟 / 沈んだ神殿 / 至聖所
- 潮汐: 移動のたびに干潮 → 中潮 → 満潮が巡り、行ける場所が変わる。法則のヒントは「潮汐暦」に
- 正気度(SANITY): 異形の光景を見ると減る。0になると発狂。赤い視界と心臓の音は危険のサイン
- 夜明けまでの刻限: 01:00スタート。朝を迎えると結末が変わる
- エンディングは5種（脱出 / 封印 / 深淵の目覚め / 発狂 / 夜明け）

### 序盤のヒント（ネタバレ注意）

- 机の「日誌」をよく読むこと。金庫の合言葉は悲しみ・沈黙・海
- 灯りがなければ暗い場所は危険。オイルとマッチとランタンを揃える
- 干潮のときにだけ渡れる場所がある。潮汐暦の法則を数えて待とう
- 行き詰まったら HINT ボタン。手掛かりの多くはメモ・写真・落書きに書かれている

### 動作環境と注意事項

- 近年の主要ブラウザ（Chrome / Edge / Firefox / Safari）で動作
- スマートフォンは横画面で遊んでください（縦のままだと回転を促す画面が出ます）
- 通信を伴うファイル・画像は使用していません（効果音もすべてプログラム生成）
- シェアウェア・再配布はご自由に。クトゥルー神話原作部分は公開範囲の範囲で自作の翻案です

## English

### How to Play

1. Open index.html in a browser (double-click, or copy the file to your phone and open it).
2. Tap "START" on the title screen. To resume, use "CONTINUE" or "LOAD 1 / LOAD 2".
3. Tap / click objects to examine the scene and combine items to find your way out.

### Controls

- Tap / click an object: examine or move between places
- Tap an inventory item once: select it (slot turns gold)
- With an item selected, tap another object: use it there
- Tap the same item again: use it alone / deselect
- HINT button: a hint tailored to your location and progress
- "SOUND" button (top right): sound effects ON / OFF (remembered)
- "日本語 / EN" button (top right): language switch (remembered)
- Menu: SAVE 1 / SAVE 2 / LOAD 1 / LOAD 2 / AUTO / RESTART / TITLE

### Save Data

- Autosave: written to the AUTO slot on every move
- Manual saves: to slots 1 and 2 from the menu (with overwrite confirmation)
- Saves live in browser localStorage — they do not carry across browsers or devices

### Game Systems

- 12 locations: bedroom / kitchen / foyer / stair turret / lamp room / cellar / dock / boat / rocks / sea cave / drowned temple / sanctum
- Tides: every move shifts LOW → MID → HIGH, and some places can only be reached at certain tides. The rule is written in the tide almanac
- SANITY: watching horrific things lowers it. At zero you are lost to madness. Red vision and a heartbeat are warning signs
- A clock counts toward dawn from 01:00 — reaching morning changes your ending
- 5 endings (escape / the seal / the awakening / madness / dawn)

### Early-Game Hints (light spoilers)

- Read the diary on the desk. The safe remembers grief, silence, sea
- You will need light for the dark places: gather lantern, oil and matches
- Some passages open only at low tide — count the tide cycle and wait
- Stuck? Press HINT. Most clues are written in notes, photos and scratches

### Requirements & Notes

- Works in modern Chrome / Edge / Firefox / Safari
- On phones, play in landscape (a rotate prompt appears in portrait)
- No network files or images of any kind (all sound is generated by code)
- The Cthulhu Mythos material here is an original arrangement of public-domain themes
